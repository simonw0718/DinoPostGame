# 恐龍郵局・英文單字任務

給約 4–8 歲孩子自行操作的聽音選圖遊戲。每題聽美式英文發音，從四張圖片中選答案；答對後四張卡翻面顯示繁體中文與逐字注音。介面以手機為優先，也支援平板與桌面。

## 目前功能

- 359 個詞：一般詞 324 個，分三級（52／143／129）；恐龍與史前夥伴 35 個，獨立成「恐龍挑戰」。
- 每回合預設 5 題，可在設定中改為 3–10 題；顯示第一次就答對的題數。
- 題目進入時播放單字錄音，可按「再聽」重播；答錯、答對、完成各有短音效。
- 選項答對後直接翻面。中文字與右側直排注音固定成對，包含聲調和輕聲點。
- 數字單字一到十優先以阿拉伯數字 emoji（1️⃣～🔟）作選項及題庫預覽；數字題優先提供其他數字作干擾選項，已生成的數字插畫保留作候選素材。
- 兩種結算畫面輪替；題目及結算畫面皆可回首頁。
- 設定內有題庫管理子頁面：可搜尋、篩選、預覽圖片及發音，查看各級啟用數量，並個別開關單字。開關保存在目前裝置的瀏覽器，下回合生效；會防止設定造成題數或四選一圖片不足。
- 設定內的作答紀錄保存此裝置最近 10 個已完成回合；出題會優先複習曾答錯的詞，並減少緊接著重複出題。每回合目標詞不重複，干擾選項不重複中文意思或圖片。
- 手機直向畫面依可用高度調整首頁、題目與結算版面；短螢幕仍可看見四張選項與下一題按鈕。
- 首頁、遊戲與結算各自從八位夥伴中抽三位登場，新增閃閃；遊戲角色使用透明背景姿勢圖，保留影格原始比例，並依正誤切換動作。角色載入完成與容器尺寸改變時會重新計算顯示大小。
- 遊戲畫面的去背角色放大，可跨題目信封邊緣；四張圖片與下一題維持可見、可操作。
- 開始按鈕會在同一次點擊事件播放預先選好的第一題錄音，以改善 iOS 首題靜音；重播鍵仍可手動播放。遊戲按鈕阻止雙點縮放。
- 恐龍長名稱在手機題目框內換行並縮小到可讀尺寸；「重聽」保留 44px 圖示按鈕，避免被擠出邊框。
- 原本從 kidsapp 匯入並在題目中使用的 56 張圖片，已由兩張 6×5 候選圖組重新製作，再以本機程式切圖接入。圖組與逐格來源對照在 `dist/assets/rebuilt/`。
- 其中八種恐龍已依 Design Master 風格重新繪製成 4×2 圖組，裁為透明選項圖；底排的愛德蒙頓龍、馬門溪龍、異特龍、冠龍各自鏡像朝右。來源及雜湊記於 `dist/assets/rebuilt/manifest.json`，可用 `tools/crop_dinosaur_grid.py` 重現裁切。
- 新增詞（目前保留 97 詞）有四張 6×5 圖組切出的候選圖片與 Samantha 美式英語 MP3；逐格對照與雜湊在 `dist/assets/rebuilt/new100/manifest.json`，產生流程見 `tools/add_100_words.py`。

## 本機預覽

這是沒有建置步驟的靜態網站。於倉庫根目錄執行：

```sh
python3 -m http.server 4173 -d dist
```

瀏覽 `http://localhost:4173/`。直接以 `file://` 開啟時，瀏覽器可能無法讀取題庫 JSON。

## Cloudflare 靜態託管

目前網站由 **Cloudflare Worker Static Assets** 提供：[開啟遊戲](https://dinopostgame.simonw0718.workers.dev/)。這個 Worker 只提供 `dist/` 的靜態檔案，沒有執行伺服器程式。Cloudflare 已連接此 GitHub 倉庫，production branch 為 `main`，Build command 留空，Deploy command 為 `npx wrangler deploy`，根目錄為倉庫根目錄。Cloudflare 建置紀錄顯示自動偵測為 `Static`，輸出目錄為 `dist`。

因此現有的 Worker 已符合靜態網站託管需求。若未來需要 Pages 專屬流程，可以另建 Pages 專案；目前不需要為了顯示這個網站而遷移。

## 題庫維護

`dist/data.json` 是唯一正式題庫。每筆使用穩定 `id`、英文 `en`、中文 `zh`、對應每個國字的 `zhuyin`、`difficulty`、`category`、圖像欄位，以及美術狀態 `artStatus`（`emoji`／`candidate` 候選／`approved` 已審核）。英文音檔放在 `dist/assets/audio/<id>.mp3`；359 詞的中文發音由 `zhAudio` 指向 `dist/assets/audio/zh/<id>.mp3`。新增或修改後執行：

```sh
python3 tools/check_data.py
```

`check_data.py` 涵蓋 `tools/validate-data.mjs` 的全部檢查（沒有 Node 也能跑），另外列出多餘的音檔、送信遊戲不會出到的詞，以及缺少的角色圖。`tools/check_flow.cjs` 是手機版操作的冒煙測試（需要 Node 和 playwright），目前裡面的按鈕文字還沒跟上現在的介面。

## 共用程式與快取

`dist/shared.js` 存放三個頁面共用的程式：角色名單（目前是 AI 候選姿勢圖，尚未登錄為視覺 Master）、注音排版、選題、作答紀錄。每個 HTML 都要先載入它，再載入頁面自己的程式。檔名後面不加 `?v=`；`dist/_headers` 讓網頁、程式和題庫每次開啟都向伺服器確認是否為最新版本。新增 HTML、JS 或 CSS 檔案時，要把路徑補進 `_headers`。

介面與各批插畫為本專案衍生素材；部分早期詞彙與錄音整理自專案作者的 [kidsapp](https://github.com/simonw0718/kidsapp)。現行題庫不再引用匯入的 kidsapp 圖片；舊檔暫存於專案供來源追溯與回退。新插畫仍屬候選，需要日後逐張美術與科學辨識審核。此倉庫未宣告開源授權；使用素材前請另行確認權利。

本機 Obsidian vault 留在工作專案內，不包含在公開倉庫中。

## 英文單字音檔

143 個目標詞（非 kidapp 來源及全部恐龍）使用 Gemini 3.8 Flash-Lite TTS 的 `erinome` 女性美式聲線。20 詞試作通過後，其餘以 50、50、23 詞分組合成，再於本機按停頓裁切。檔案仍使用 `dist/assets/audio/<id>.mp3`，遊戲播放方式不需更動。來源與 SHA-256 記錄於 `tools/gemini-tts-production-manifest.json`；本機原音、切點、舊檔備份保存在忽略 Git 的 `audio-pilot/`。API key 保存在個人設定目錄，未納入專案。

## 注音送信試玩

從獨立的選遊戲首頁進入「找圖片」或「注音送信」各自的任務準備頁。送信準備頁沿用郵局場景、三位角色、模式選擇、難度條和開始按鈕，再進入獨立送信遊戲。每輪可選 3–10 封信，每封信顯示注音或英文單字，搭配 3 個圖片郵箱；孩子可拖信投遞，或先點信再點郵箱。答錯可重試，答對翻面展示中文與英文並推進一段路線。依送信準備頁所選的全部、第一至三級或恐龍挑戰，使用啟用中的題目，完成時將首答結果寫入既有本機紀錄格式。互動使用本地打包的 interact.js 與 Motion，不依賴外部 CDN。

注音送信的答案會在同一封信背面翻出並蓋郵戳；按下一封時才投入郵箱上方郵槽。注音逐符號直排，聲調紅色，輕聲點在音節上方。

注音送信上方路線每輪輪替一位現有去背角色；八位角色輪完前不重複，保持每幀原始比例。

信件正面與背面郵戳使用現有品牌郵戳徽章。注音送信頁的兒童可見中文字比照卡片遊戲，使用中文字旁直排注音與紅色聲調。

注音送信試玩頁使用配對遊戲同款品牌列、回首頁及設定入口。信件從郵袋沿輸送帶進場；原始品牌郵戳由本機工具去背裁切為透明素材，背面蓋戳尺寸加大。首頁現在是獨立的雙遊戲選擇頁；找圖片及注音送信各有同款任務準備頁，送信可選全部／分難度／恐龍挑戰。

注音送信設定可選全部、第一至第三級、恐龍挑戰；模式與配對遊戲採相同題庫分級，三個郵箱只取自當前範圍。模式選擇儲存在本機並於下一回合生效。

## 遊戲答題方式（本機開發中）

「找圖片」可切換四圖選答與「找單字」。後者會在題目卡顯示圖片包裹封面，保留英文發音與重聽，四個選項改為英文單字；答對後包裹蓋章飛出，選項翻面顯示中文與注音。兩種答題方式都有自動發音開關。

「送信」可切換看注音或看英文單字，與三個圖片郵箱配對。看注音時自動發中文音，看英文單字時自動發英文音；兩者都可關閉自動發音並手動重聽。啟用自動發音時，進入送信頁後點「開始送信」，第一題便在同一次操作中播放；答對翻面蓋郵戳時播放本機音檔，完成整回合播放慶祝音檔，完成頁也可手動重聽。每回合可選 3–10 封，全部／分難度／恐龍挑戰與既有題庫開關、作答紀錄共用。`cauliflower` 已移除，目前 359 詞。

## 中文單字發音

359 詞皆有繁體中文發音。F11／F04／R13／R14／R01 五組長音檔與飛飛 R22 試作的 48 個已審聽詞，由本機 ffmpeg 裁切；本機 Whisper 用來核對詞序與漏詞，不用辨識文字命名。英文發音保持原檔。找圖片答對翻面後可點正確卡片聽中文；注音送信答對後可按「聽中文」。語音長檔與金鑰保留在本機，公開倉庫只放遊戲使用的逐詞 MP3。
